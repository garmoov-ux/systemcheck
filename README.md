# SystemCheck - 무인교통단속장비 상태 점검 및 생존신호 전송 시스템 (v2.1.0)

- **개발·기술지원**: ㈜이노네트웍스 강홍선 (`s_gain@naver.com`)

무인교통단속장비의 네트워크 연결 상태(**응답 확인**, **원격 데스크톱 포트 `3389`**, **원격 제어 포트 `5900`**)를 비동기 병렬로 고속 점검하고, 정상 가동 중인 장비의 센터 생존신호(`KeepAlive`)를 자동 전송하는 Windows 10+ 전용 데스크톱 관제 애플리케이션입니다.

---

## 1. 배포 및 단독 실행 안내 (`SystemCheck_Portable.exe`)

빌드 완료 후 `release/SystemCheck_Portable.exe` **파일 1개만** 원하는 폴더에 복사하여 바로 사용할 수 있습니다.
- 실행 파일 이름을 `SystemCheck.exe` 등 원하는 이름으로 변경해도 정상 동작합니다.
- 최초 실행 시 실행 파일이 위치한 폴더를 기준으로 아래 파일과 폴더를 스스로 자동 생성합니다:
  - `config.json`: 환경 설정 파일 (`./log` 상대경로 기본 적용)
  - `data/app.db`: 내장 데이터베이스 파일 (초기 110대 운용 장비 현장 위치명 자동 시드, 전체 653대 현장 마스터 사전 내장)
  - `log/`: 일자별 상세 한글 로그(`YYYYMMDD_system_check.log`, `YYYYMMDD_device_check.log`) 기록 폴더

## 2. 핵심 기능 및 v2.1.0 주요 개선 사항

1. **컴팩트 창(`1040 × 680`) 및 좌측 수직 아이콘 사이드바 (`SysChk`)**
   - `현황` · `장비` · `이력` · `통계` · `로그` · `설정` · `정보` 7개 본문 메뉴와 하단 `[점검중/정지됨]`, `[즉시점검]` 퀵 액션 버튼으로 구성된 일관된 관제 UI를 제공합니다.

2. **전체 653대 현장 마스터 내장 및 110대 운용 장비 현장명 자동 매핑**
   - 기존 `data.csv` 110대 장비에 현장 설치 위치(`중문 SP리조트 앞(관광단지방면)` 등)가 기본 매핑되어 있습니다.
   - **장비 목록 관리** 화면에서 653대 현장 마스터(장비번호·설치 위치·IP·제조사)를 검색하여 원클릭으로 입력폼에 채울 수 있으며, 기존 6컬럼 `data.csv`, 7컬럼 CSV, 22컬럼 현장 마스터 CSV(`devices_*.csv`) 가져오기를 모두 호환 지원합니다.

3. **월별 통계 3탭 인터랙티브 호버 차트 및 A4 PDF 보고서 출력**
   - `[ < ] [ YYYY년 MM월 ] [ > ]` 아이콘 스테퍼로 월별 가동률 통계를 조회합니다.
   - **일자별 가동 추이**, **장비별 가동률 비교**, **상태 · 포트 분포(SVG 도넛 차트)** 3가지 탭 차트와 마우스 호버 상세 툴팁을 제공하며, 차트가 포함된 **A4 PDF 보고서 출력**을 지원합니다.

4. **실시간 운용 로그 조회 및 프로그램 정보 (본문 탭)**
   - **로그** 메뉴에서 `시스템점검` / `장비상세` 로그를 3초 주기로 실시간 조회·필터링하고 로그 폴더를 바로 열 수 있습니다.
   - **정보** 메뉴에서 프로그램 명세(`속성 : 값`), 버전 업데이트 이력, 현장 유지보수 폴더 바로 열기 기능을 제공합니다.

## 3. 개발 및 빌드 명령어

```powershell
# 1. 저장소 복제 및 초기 환경 구성
git clone https://github.com/garmoov-ux/systemcheck.git
cd systemcheck
npm run setup

# 2. 타입 검사 및 단위 테스트 실행
npm run typecheck
npm test

# 3. 개발 모드 실행
npm run dev

# 4. Windows 배포용 실행 파일 빌드 (release/SystemCheck_Portable.exe, SystemCheck_Setup.exe)
npm run dist:win
```
